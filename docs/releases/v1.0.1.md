# JAX-MD 1.0.1

Maintenance release collecting simulation correctness and input-safety fixes
since v1.0.0.

## Fixes and validation

- Correct pair-energy normalization and XYZ input parsing.
- Validate YAML parameters, XYZ coordinates, and direct simulation inputs;
  resolve relative XYZ paths from the configuration directory.
- Reject initial overlapping particles, including periodic coincidences.
- Safely exclude self-interactions before evaluating inverse powers, and stop
  nonfinite simulations with step, time, and parameter diagnostics.
- Add deterministic initialization controls and regression coverage for energy
  and momentum conservation, periodic invariance, and timestep convergence.

## Compatibility notes

Malformed inputs that previously slipped through validation now fail clearly.
The CLI exits with status 2 for invalid inputs or nonfinite simulations.
The Lennard-Jones potential is unchanged for distinct particles. Numerical
safety checks run every step and add synchronization and energy-evaluation cost.
Physics regression tests use double precision; the CLI retains JAX's default
precision unless configured otherwise.

## Known limitations

- Trajectories remain in memory and are written to `output.arc` only after a
  successful run; interrupted runs lose trajectory output, and an existing
  output file can be overwritten (#17).
- Sampling labels and physical-time reporting need correction (#18).
- Animation initialization and the meaning of the `center` option need
  correction/clarification (#20).
- Pair calculations use quadratic memory and work; large-system optimization
  remains pending (#19).

These limitations remain tracked for subsequent releases.
